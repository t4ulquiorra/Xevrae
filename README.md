# Xevrae

A YouTube Music client for Android.

## Build

### Requirements
- JDK 21
- Android SDK

### APK Variants
- **Full** — includes Sentry crashlytics
- **FOSS** — clean build, no tracking

### GitHub Actions
- Push to `main` → builds Full + FOSS release APKs + Desktop packages
- Push to `dev` → builds FOSS APK only
